# TruthLayer v0.1

Evidence-first scholarship claim inspection — **static research demo**.

## Run
Open `index.html` locally. No build step or API key required.

## Publish with GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and Save. GitHub will show the published URL when deployment completes.

## Important limitations
This is an interface prototype, **not a live fact-checker**. It intentionally returns Unverified for submitted claims. It does not retrieve live sources, authenticate documents, or make verified findings. The source links are starting points only, not citations for a submitted claim. The evaluation dataset remains draft until independent human review.

Do not enter Aadhaar numbers, OTPs, bank credentials, or other sensitive information.
